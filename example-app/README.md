# Пример первоначальной структуры для Bitrix (БУС) приложения

## 🚀 Быстрый старт

- ⬇️ Скачайте example-app (переименуйте раздел под ваш проект).
- 📄 Скопируйте `.env.exmample` в `.env` в корень проекта (см. таблицу с переменными).
- ⚡ Запустите проект выплнив команду из корня проекта: `make up`.
- 📊 В логах контейнера `application` вам будет доступен процесс создания проекта.
- ✅ Завершением сборки можно считать появление строки `✅ КОНТЕЙНЕР ГОТОВ — ЗАПУСКАЮ NGINX И PHP-FPM`.

| Название переменной  | Описание переменной                                                                                                                                                                                                 | Требуется |
| :------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------- |
| APP_HOST             | Хост вашего проекта                                                                                                                                                                                                 | ✅        |
| APP_PATH             | Путь от корня до проекта внутри контейнера                                                                                                                                                                          | ✅        |
| DB_HOST              | Хост базы данных (хостом БД является название контейнера СУБД из docker-compose.yml; используется для СУБД)                                                                                                         | ✅        |
| DB_DATABASE          | Название базы данных (используется для СУБД)                                                                                                                                                                        | ✅        |
| DB_USER              | Имя пользователя для базы данных (используется для СУБД)                                                                                                                                                            | ✅        |
| DB_PASSWORD          | Пароль пользователя для базы данных (используется для СУБД)                                                                                                                                                         | ✅        |
| DB_ROOT_PASSWORD     | Секретный пароль пользователя для базы данных (используется для СУБД)                                                                                                                                               | ✅        |
| BITRIX_CRON_ENABLED  | Вкл/выкл CRON (1 - вкл.; раз в минуту): `bitrix/php_interface/cron_events.php`. Допустимы только `0` или `1`                                                                                                        | ✅        |
| MAILPIT_ENABLED      | Вкл/выкл mailpit (1 - вкл.). Если задана — только `0` или `1`; любое другое значение — ошибка при старте контейнера                                                                                                 | ❌        |
| MAILPIT_HOST         | Хост mailpit. Обязательна, если `MAILPIT_ENABLED=1`                                                                                                                                                                 | ❌        |
| BUILD_BITRIX_VERSION | [Редакция БУС](https://www.1c-bitrix.ru/download/cms.php#tab-subsection-3): `start_encode` (по умолчанию), `standard_encode`, `small_business_encode`, `business_encode`. Любое другое значение — ошибка при старте контейнера | ❌        |

### Установка 1C-Bitrix (БУС)

😎 Если сборка проекта успешно завершена, то можете перейти на страницу `http://APP_HOST` (заменить **APP_HOST** на хост из `.env` файла). Вы должны увидеть стартовую страницу установки `БУС`.

1. На странице `Предварительная проверка` все обязательные параметры и доступы к диску должны быть выделены зеленым
   цветом.
2. На странице `Создание базы данных` указать следующие данные: `Сервер` (название вашего контейнера СУБД; значение из
   переменной DB_HOST), `Имя пользователя` (значение из переменной DB_USER), `Пароль` (значение из переменной
   DB_PASSWORD), `Имя базы данных` (значение из переменной DB_DATABASE). Больше ничего менять не надо.
3. На странице `Выберите решение для установки` выберите любой из готовых шаблонов (рекомендуется НЕ использовать
   `Загрузить из Маркетплейс`, так как эти шаблоны от сторонних разработчиков и могут содержать ошибки).
4. После установки БУС вы попадете на главную страницу вашего сайта с предустановленным шаблоном. Для перехода в
   админ-панель БУС перейдите на страницу `http://localhost/bitrix` или `http://APP_HOST/bitrix`
5. 🔥**БУС** успешно установлен!

## 🛠️ Доп. настройки

### ⚙️ Проставить переменные .env в конфиги

👇 Следующие значения в файле `/bitrix/.settings.php` заменить:

```php
[
  'debug' => (bool)$_ENV["APP_DEBUG"], # если указывали APP_DEBUG в .env
];
```

```php
[
  'host' => $_ENV["DB_HOST"],
  'database' => $_ENV["DB_DATABASE"],
  'login' => $_ENV["DB_USER"],
  'password' => $_ENV["DB_PASSWORD"],
];
```

👇 Следующие значения в файле`/bitrix/php_interface/dbconn.php`заменить:

```php
$DBDebug = (bool)$_ENV["APP_DEBUG"];
$DBDebugToFile = (bool)$_ENV["APP_DEBUG"];
```
